# This is for you

A quiet, cinematic bouquet of nine individually animated baby-pink SVG tulips.
Made with plain HTML, CSS, and JavaScript. No dependencies, external images,
fonts, build step, or internet connection required.

## Open locally

Double-click `index.html`, or run:

```sh
npm start
```

Then open http://localhost:3000. Set `PORT` to choose another port.

## The experience

- A black screen and a centered dedication, held for about two seconds.
- Nine curved stems grow, leaves unfurl, and buds form at staggered intervals.
- Six separate petals per flower open in sequence, with varied final bloom stages.
- A restrained pink glow and sparse upward-floating particles.
- Independent, gentle swaying after each flower blooms.
- Replay and pause controls appear with the closing caption.
- Reduced-motion preferences reveal a still bouquet after the dedication.
- Animation pauses while the browser tab is hidden.

## Customize

`script.js` contains the nine flower configurations, petal shapes, and three
pink palettes. Change `bloom` (0–1), `tilt`, `size`, `delay`, or the flower
coordinates to adjust the arrangement. `styles.css` contains the animation
keyframes and responsive layout. The entire scene is vector artwork.
